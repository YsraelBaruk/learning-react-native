# First App React Native

## Instruções

### Pré-requisitos
- Node.js - 🔗 [baixe aqui](https://nodejs.org/pt/download)

Clone o projeto:
```bash
git clone https://github.com/YsraelBaruk/first-app-react-native
```

Entre no diretório:
```bash
cd first-app-react-native
```

## Para rodar o projeto

Instale as dependências:
```bash
npm install
```

Inicie o projeto:
```bash
npm run start
```

--- 

## Testando no celular
Você pode testar no seu celular instalando o aplicativo [Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent&pcampaignid=web_share).

Quando aparecer um QR Code no terminal, escaneie-o usando o aplicativo Expo Go instalado em seu dispositivo.
